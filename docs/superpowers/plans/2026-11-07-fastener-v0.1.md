# Fastener v0.1 (headless core + check) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a daemonless Go CLI that launches headless agent sessions (Claude Code, Codex, Pi) through a per-session monitor process. It must be able to list, inspect, follow, wait on, stop and remove those sessions, and prove a backend works with `fastener check`.

**Architecture:** One binary with two roles. The CLI resolves a TOML backend profile into a launch *plan*, writes it to a per-session state directory, and starts `fastener _monitor` detached via `setsid`. The monitor:
- spawns the agent in its own process group;
- writes stdout to `output.log` and stderr to `stderr.log`;
- feeds stdout to a named parser;
- enforces time limits and turns signals into recorded `ended_by` facts;
- is the only writer of `status.json` while it lives.

Every other command is a short-lived CLI invocation that reads those files and checks process liveness by pid + start time + boot ID.

**Tech Stack:**
- Go 1.25.
- `github.com/BurntSushi/toml` v1.5.0 (profiles, config).
- `golang.org/x/sys` v0.47.0 (`unix.SignalName`/`SignalNum`, macOS sysctl).
- Standard library `flag`, `encoding/json`, `os/exec`.
- No CLI framework.

**Spec:** `docs/superpowers/specs/2026-11-07-fastener-design.md`. Read §2–§7, §10 and §12 before starting.

## Refinements to the spec made while planning (keep the spec in sync in Task 16)

1. **Environment precedence needs two fields.** `session.json` stores `env_base` (captured passthrough values) and `env` (`--env` values) separately. The spec's single `env` field cannot express *base → env-file → --env* precedence when the env-file is read later, by the monitor.
2. **`argv[0]` is resolved to an absolute path at plan time**, against the session's PATH. The monitor never does a PATH lookup.
3. **`prompt = "arg"` always appends `--` and then the prompt**, so a prompt starting with `-` can't become a flag.
4. **`claude-stream-json` moves into v0.1**, because `check` is useless for Claude without it. Codex and Pi ship with `parser = "none"` until v0.2. With `none`, check's `parse` step is `skip`, and `reply` searches `output.log`.
5. **`logs --stderr`** shows `stderr.log`.
6. **`--launcher systemd` is a clear error in v0.1.**
7. **Pi has no permission system.** Its profile defines only `skip = []`, so Pi sessions need `--permissions skip`. This is no silent fallback applied honestly.
8. **The Codex profile includes `--skip-git-repo-check`.** Fastener sessions name their working directory explicitly, and `check` uses a temporary non-git directory.
9. **Labels are stored in v0.1** (`check` uses `fastener.check=true`). `ps --filter` is v0.2.
10. **`--model` values starting with `-` are rejected**, as an injection guard.
11. **`usage.input_tokens` is all input tokens for the run**, including cache reads and writes.
12. **Two environment variables override the state and config locations:** `FASTENER_STATE_DIR` and `FASTENER_CONFIG_DIR`. The tests need them, and they're useful to users.

```go
// Package proc identifies processes robustly. A pid alone can be reused, so an
// Identity carries the process start time and is only valid on the boot it was
// recorded on (callers keep the boot ID next to it).
package proc

import (
	"errors"
	"os"
	"syscall"
	"time"
)

// ErrNoProcess means the process does not exist, is a zombie, or is not the
// process an Identity names.
var ErrNoProcess = errors.New("no such process")

// MarkerEnv tags every process of one session generation.
const MarkerEnv = "FASTENER_SESSION"

// Identity names one process instance.
type Identity struct {
	PID       int    `json:"pid"`
	StartTime uint64 `json:"start_time"` // Linux: clock ticks since boot; macOS: µs since epoch
}

// Of returns the identity of a running process.
func Of(pid int) (Identity, error) {
	st, err := StartTime(pid)
	if err != nil {
		return Identity{}, err
	}
	return Identity{PID: pid, StartTime: st}, nil
}

// Self returns the identity of the calling process.
func Self() (Identity, error) { return Of(os.Getpid()) }

// Alive reports whether id still names a live (non-zombie) process on the boot bootID.
func Alive(id Identity, bootID string) bool {
	if id.PID <= 0 || bootID == "" {
		return false
	}
	cur, err := BootID()
	if err != nil || cur != bootID {
		return false
	}
	st, err := StartTime(id.PID)
	return err == nil && st == id.StartTime
}

// Signal sends sig to id after re-verifying the identity.
func Signal(id Identity, bootID string, sig syscall.Signal) error {
	if !Alive(id, bootID) {
		return ErrNoProcess
	}
	return syscall.Kill(id.PID, sig)
}

// FindMarked returns the live processes in process group pgid whose environment
// contains MarkerEnv=marker, on boot bootID. A process without the marker is
// never returned, so a reused pgid cannot redirect a signal to a stranger.
func FindMarked(pgid int, marker, bootID string) ([]Identity, error) {
	if pgid <= 0 || marker == "" {
		return nil, nil
	}
	cur, err := BootID()
	if err != nil {
		return nil, err
	}
	if cur != bootID {
		return nil, nil
	}
	pids, err := PIDs()
	if err != nil {
		return nil, err
	}
	want := MarkerEnv + "=" + marker
	var out []Identity
	for _, pid := range pids {
		g, err := PGID(pid)
		if err != nil || g != pgid {
			continue
		}
		env, err := Environ(pid)
		if err != nil || !has(env, want) {
			continue
		}
		id, err := Of(pid)
		if err != nil {
			continue
		}
		out = append(out, id)
	}
	return out, nil
}

// WaitGone polls until none of ids is alive or d elapses, and returns the survivors.
func WaitGone(ids []Identity, bootID string, d time.Duration) []Identity {
	deadline := time.Now().Add(d)
	for {
		var left []Identity
		for _, id := range ids {
			if Alive(id, bootID) {
				left = append(left, id)
			}
		}
		if len(left) == 0 || time.Now().After(deadline) {
			return left
		}
		time.Sleep(50 * time.Millisecond)
	}
}

func has(env []string, kv string) bool {
	for _, e := range env {
		if e == kv {
			return true
		}
	}
	return false
}
```

```go
//go:build linux

package proc

import (
	"errors"
	"fmt"
	"io/fs"
	"os"
	"strconv"
	"strings"
)

// readStat parses /proc/<pid>/stat. comm (field 2) may contain spaces and
// parentheses, so fields are counted from after the last ')'.
func readStat(pid int) (state byte, pgid int, start uint64, err error) {
	b, err := os.ReadFile("/proc/" + strconv.Itoa(pid) + "/stat")
	if err != nil {
		if errors.Is(err, fs.ErrNotExist) {
			err = ErrNoProcess
		}
		return 0, 0, 0, err
	}
	s := string(b)
	i := strings.LastIndexByte(s, ')')
	if i < 0 {
		return 0, 0, 0, fmt.Errorf("proc: malformed stat for pid %d", pid)
	}
	f := strings.Fields(s[i+1:]) // f[0] is field 3 (state); field N is f[N-3]
	if len(f) < 20 {
		return 0, 0, 0, fmt.Errorf("proc: short stat for pid %d", pid)
	}
	if pgid, err = strconv.Atoi(f[2]); err != nil { // field 5
		return 0, 0, 0, err
	}
	if start, err = strconv.ParseUint(f[19], 10, 64); err != nil { // field 22
		return 0, 0, 0, err
	}
	return f[0][0], pgid, start, nil
}

// StartTime returns the start time of a live process (ErrNoProcess for zombies).
func StartTime(pid int) (uint64, error) {
	state, _, start, err := readStat(pid)
	if err != nil {
		return 0, err
	}
	if state == 'Z' || state == 'X' {
		return 0, ErrNoProcess
	}
	return start, nil
}

func PGID(pid int) (int, error) {
	_, pgid, _, err := readStat(pid)
	return pgid, err
}

func BootID() (string, error) {
	b, err := os.ReadFile("/proc/sys/kernel/random/boot_id")
	if err != nil {
		return "", err
	}
	return strings.TrimSpace(string(b)), nil
}

// Environ returns the process's initial environment (readable for own processes).
func Environ(pid int) ([]string, error) {
	b, err := os.ReadFile("/proc/" + strconv.Itoa(pid) + "/environ")
	if err != nil {
		return nil, err
	}
	s := strings.TrimRight(string(b), "\x00")
	if s == "" {
		return nil, nil
	}
	return strings.Split(s, "\x00"), nil
}

func PIDs() ([]int, error) {
	ents, err := os.ReadDir("/proc")
	if err != nil {
		return nil, err
	}
	var out []int
	for _, e := range ents {
		if pid, err := strconv.Atoi(e.Name()); err == nil {
			out = append(out, pid)
		}
	}
	return out, nil
}
```

```go
//go:build darwin

package proc

import (
	"bytes"
	"encoding/binary"

	"golang.org/x/sys/unix"
)

const sZomb = 5 // SZOMB in <sys/proc.h>

func kinfo(pid int) (*unix.KinfoProc, error) {
	k, err := unix.SysctlKinfoProc("kern.proc.pid", pid)
	if err != nil {
		return nil, ErrNoProcess
	}
	if int(k.Proc.P_pid) != pid {
		return nil, ErrNoProcess
	}
	return k, nil
}

func StartTime(pid int) (uint64, error) {
	k, err := kinfo(pid)
	if err != nil {
		return 0, err
	}
	if k.Proc.P_stat == sZomb {
		return 0, ErrNoProcess
	}
	tv := k.Proc.P_starttime
	return uint64(tv.Sec)*1_000_000 + uint64(tv.Usec), nil
}

func PGID(pid int) (int, error) {
	k, err := kinfo(pid)
	if err != nil {
		return 0, err
	}
	return int(k.Eproc.Pgid), nil
}

// BootID uses kern.bootsessionuuid; kern.boottime shifts with clock adjustments.
func BootID() (string, error) { return unix.Sysctl("kern.bootsessionuuid") }

func PIDs() ([]int, error) {
	ks, err := unix.SysctlKinfoProcSlice("kern.proc.all")
	if err != nil {
		return nil, err
	}
	out := make([]int, 0, len(ks))
	for _, k := range ks {
		out = append(out, int(k.Proc.P_pid))
	}
	return out, nil
}

// Environ parses KERN_PROCARGS2: int32 argc, exec path, NUL padding,
// argv[argc] (NUL-terminated), then environment strings until an empty one.
func Environ(pid int) ([]string, error) {
	b, err := unix.SysctlRaw("kern.procargs2", pid)
	if err != nil {
		return nil, err
	}
	if len(b) < 4 {
		return nil, ErrNoProcess
	}
	argc := int(binary.LittleEndian.Uint32(b[:4]))
	b = b[4:]
	i := bytes.IndexByte(b, 0) // end of exec path
	if i < 0 {
		return nil, nil
	}
	b = b[i:]
	for len(b) > 0 && b[0] == 0 {
		b = b[1:]
	}
	for n := 0; n < argc; n++ {
		i := bytes.IndexByte(b, 0)
		if i < 0 {
			return nil, nil
		}
		b = b[i+1:]
	}
	var env []string
	for len(b) > 0 {
		i := bytes.IndexByte(b, 0)
		if i <= 0 {
			break
		}
		env = append(env, string(b[:i]))
		b = b[i+1:]
	}
	return env, nil
}
```

```go
// Package parser extracts optional, mechanical facts from an agent's stdout,
// one line at a time. Parsers never affect the session: a bad line only
// increments ParseErrors.
package parser

import "sort"

// Fields are written into status.json; every field is optional.
type Fields struct {
	ConversationID string `json:"conversation_id,omitempty"`
	FinalMessage   string `json:"final_message,omitempty"`
	AgentError     *bool  `json:"agent_error,omitempty"`
	Usage          *Usage `json:"usage,omitempty"`
	ParseErrors    int    `json:"parse_errors,omitempty"`
}

// Usage counts all tokens the backend reported for the run.
type Usage struct {
	InputTokens  int64   `json:"input_tokens,omitempty"` // includes cache reads/writes
	OutputTokens int64   `json:"output_tokens,omitempty"`
	CostUSD      float64 `json:"cost_usd,omitempty"`
}

// Parser consumes one stdout line (without its newline) and updates f.
// It reports whether f changed. Implementations are stateless.
type Parser interface {
	Line(line []byte, f *Fields) bool
}

type none struct{}

func (none) Line([]byte, *Fields) bool { return false }

var registry = map[string]Parser{
	"none":               none{},
	"claude-stream-json": claudeStreamJSON{},
}

// Get returns the named parser.
func Get(name string) (Parser, bool) {
	p, ok := registry[name]
	return p, ok
}

// Names lists registered parser names, sorted.
func Names() []string {
	out := make([]string, 0, len(registry))
	for n := range registry {
		out = append(out, n)
	}
	sort.Strings(out)
	return out
}
```

```go
// claudeStreamJSON parses `claude -p --output-format stream-json --verbose`.
// Every event carries session_id; the final "result" event carries the reply,
// is_error, total_cost_usd and usage.
type claudeStreamJSON struct{}

type claudeEvent struct {
	Type         string   `json:"type"`
	SessionID    string   `json:"session_id"`
	Result       *string  `json:"result"`
	IsError      *bool    `json:"is_error"`
	TotalCostUSD *float64 `json:"total_cost_usd"`
	Usage        *struct {
		InputTokens              int64 `json:"input_tokens"`
		CacheCreationInputTokens int64 `json:"cache_creation_input_tokens"`
		CacheReadInputTokens     int64 `json:"cache_read_input_tokens"`
		OutputTokens             int64 `json:"output_tokens"`
	} `json:"usage"`
}

func (claudeStreamJSON) Line(line []byte, f *Fields) bool {
	if len(bytes.TrimSpace(line)) == 0 {
		return false
	}
	var e claudeEvent
	if err := json.Unmarshal(line, &e); err != nil {
		f.ParseErrors++
		return true
	}
	changed := false
	if e.SessionID != "" && e.SessionID != f.ConversationID {
		f.ConversationID = e.SessionID
		changed = true
	}
	if e.Type != "result" {
		return changed
	}
	if e.Result != nil {
		f.FinalMessage = *e.Result
		changed = true
	}
	if e.IsError != nil {
		v := *e.IsError
		f.AgentError = &v
		changed = true
	}
	if e.Usage != nil || e.TotalCostUSD != nil {
		u := &Usage{}
		if e.Usage != nil {
			u.InputTokens = e.Usage.InputTokens + e.Usage.CacheCreationInputTokens + e.Usage.CacheReadInputTokens
			u.OutputTokens = e.Usage.OutputTokens
		}
		if e.TotalCostUSD != nil {
			u.CostUSD = *e.TotalCostUSD
		}
		f.Usage = u
		changed = true
	}
	return changed
}
```

```go
// Package runenv builds an agent's environment explicitly: a passthrough base
// captured from the caller, then an env file, then --env values.
package runenv

import (
	"bufio"
	"fmt"
	"os"
	"path/filepath"
	"strings"
)

// DefaultPassthrough is the default env_passthrough list (spec §5).
var DefaultPassthrough = []string{
	"HOME", "USER", "LOGNAME", "PATH", "LANG", "LC_*", "SSH_AUTH_SOCK",
	"XDG_CONFIG_HOME", "XDG_DATA_HOME", "XDG_STATE_HOME", "XDG_CACHE_HOME", "XDG_RUNTIME_DIR",
}

// Base copies variables named in passthrough from environ. "X_*" matches a prefix.
func Base(passthrough, environ []string) []string {
	var out []string
	for _, kv := range environ {
		k, _, ok := strings.Cut(kv, "=")
		if !ok {
			continue
		}
		for _, p := range passthrough {
			if p == k || (strings.HasSuffix(p, "*") && strings.HasPrefix(k, strings.TrimSuffix(p, "*"))) {
				out = append(out, kv)
				break
			}
		}
	}
	return out
}

// ReadFile parses KEY=VALUE lines; blank lines and # comments are skipped,
// an optional leading "export " is allowed, and whitespace around key and value is trimmed.
func ReadFile(path string) ([]string, error) {
	f, err := os.Open(path)
	if err != nil {
		return nil, err
	}
	defer f.Close()
	var out []string
	sc := bufio.NewScanner(f)
	for n := 1; sc.Scan(); n++ {
		line := strings.TrimSpace(sc.Text())
		if line == "" || strings.HasPrefix(line, "#") {
			continue
		}
		line = strings.TrimPrefix(line, "export ")
		k, v, ok := strings.Cut(line, "=")
		k = strings.TrimSpace(k)
		if !ok || k == "" || strings.ContainsAny(k, " \t") {
			return nil, fmt.Errorf("%s:%d: want KEY=VALUE", path, n)
		}
		out = append(out, k+"="+strings.TrimSpace(v))
	}
	return out, sc.Err()
}

// Merge combines layers; a later layer's value wins, order of first appearance is kept.
func Merge(layers ...[]string) []string {
	idx := map[string]int{}
	var out []string
	for _, layer := range layers {
		for _, kv := range layer {
			k, _, _ := strings.Cut(kv, "=")
			if i, ok := idx[k]; ok {
				out[i] = kv
				continue
			}
			idx[k] = len(out)
			out = append(out, kv)
		}
	}
	return out
}

// Get returns the value of key in env, or "".
func Get(env []string, key string) string {
	for i := len(env) - 1; i >= 0; i-- {
		if k, v, ok := strings.Cut(env[i], "="); ok && k == key {
			return v
		}
	}
	return ""
}

// LookPath finds name on pathList (colon-separated). Relative PATH entries are
// ignored. A name containing '/' must be an absolute executable path.
func LookPath(name, pathList string) (string, error) {
	if strings.ContainsRune(name, '/') {
		if filepath.IsAbs(name) && isExec(name) {
			return name, nil
		}
		return "", fmt.Errorf("%q is not an absolute path to an executable", name)
	}
	for _, dir := range filepath.SplitList(pathList) {
		if !filepath.IsAbs(dir) {
			continue
		}
		p := filepath.Join(dir, name)
		if isExec(p) {
			return p, nil
		}
	}
	return "", fmt.Errorf("%q not found on the session PATH (%s)", name, pathList)
}

func isExec(p string) bool {
	fi, err := os.Stat(p)
	return err == nil && fi.Mode().IsRegular() && fi.Mode()&0o111 != 0
}
```

```go
	"github.com/BurntSushi/toml"

type Config struct {
	Retention          string   `toml:"retention"` // used from v0.2
	DefaultPermissions string   `toml:"default_permissions"`
	HandshakeTimeout   string   `toml:"handshake_timeout"`
	Launcher           string   `toml:"launcher"`
	EnvPassthrough     []string `toml:"env_passthrough"`
	DetachKey          string   `toml:"detach_key"` // used from v0.3
}

// Dir is $FASTENER_CONFIG_DIR, else $XDG_CONFIG_HOME/fastener, else ~/.config/fastener.
func Dir() string {
	if v := os.Getenv("FASTENER_CONFIG_DIR"); v != "" {
		return v
	}
	if v := os.Getenv("XDG_CONFIG_HOME"); v != "" {
		return filepath.Join(v, "fastener")
	}
	home, _ := os.UserHomeDir()
	return filepath.Join(home, ".config", "fastener")
}

// BackendsDir holds user backend profiles (<name>.toml).
func BackendsDir() string { return filepath.Join(Dir(), "backends") }

func defaults() Config {
	return Config{
		Retention:        "168h",
		HandshakeTimeout: "5s",
		Launcher:         "auto",
		EnvPassthrough:   append([]string(nil), runenv.DefaultPassthrough...),
		DetachKey:        "ctrl-]",
	}
}

// Load returns defaults overlaid with config.toml, if present. Unknown keys are errors.
func Load() (Config, error) {
	c := defaults()
	path := filepath.Join(Dir(), "config.toml")
	b, err := os.ReadFile(path)
	if errors.Is(err, fs.ErrNotExist) {
		return c, nil
	}
	if err != nil {
		return c, err
	}
	md, err := toml.Decode(string(b), &c)
	if err != nil {
		return c, fmt.Errorf("%s: %w", path, err)
	}
	if und := md.Undecoded(); len(und) > 0 {
		keys := make([]string, len(und))
		for i, k := range und {
			keys[i] = k.String()
		}
		return c, fmt.Errorf("%s: unknown keys: %s", path, strings.Join(keys, ", "))
	}
	for _, d := range []struct{ name, v string }{{"handshake_timeout", c.HandshakeTimeout}, {"retention", c.Retention}} {
		if _, err := time.ParseDuration(d.v); err != nil {
			return c, fmt.Errorf("%s: %s: %w", path, d.name, err)
		}
	}
	return c, nil
}

// Handshake returns the handshake timeout (validated by Load).
func (c Config) Handshake() time.Duration {
	d, err := time.ParseDuration(c.HandshakeTimeout)
	if err != nil || d <= 0 {
		return 5 * time.Second
	}
	return d
}
```

```go
func DirFor(name string) Dir { return Dir(filepath.Join(SessionsDir(), name)) }

func (d Dir) join(p ...string) string      { return filepath.Join(append([]string{string(d)}, p...)...) }
func (d Dir) SessionPath() string           { return d.join("session.json") }
func (d Dir) PromptPath() string            { return d.join("prompt.txt") }

func (d Dir) MonitorLog() string            { return d.join("monitor.log") }

// Create reserves name atomically: mkdir either succeeds or the name is taken.
func Create(name string) (Dir, error) {
	if !ValidName(name) {
		return "", fmt.Errorf("invalid session name %q (want %s)", name, nameRE)
	}
	if err := os.MkdirAll(SessionsDir(), 0o700); err != nil {
		return "", err
	}
	d := DirFor(name)
	if err := os.Mkdir(string(d), 0o700); err != nil {
		if errors.Is(err, fs.ErrExist) {
			return "", fmt.Errorf("%w: %s", ErrNameTaken, name)
		}
		return "", err
	}
	if err := os.Mkdir(d.join("generations"), 0o700); err != nil {
		return "", err
	}
	return d, nil
}

// Names lists existing sessions, sorted.
func Names() ([]string, error) {
	ents, err := os.ReadDir(SessionsDir())
	if errors.Is(err, fs.ErrNotExist) {
		return nil, nil
	}
	if err != nil {
		return nil, err
	}
	var out []string
	for _, e := range ents {
		if e.IsDir() && ValidName(e.Name()) {
			out = append(out, e.Name())
		}
	}
	return out, nil
}

var b32 = base32.NewEncoding("abcdefghijklmnopqrstuvwxyz234567").WithPadding(base32.NoPadding)

func randToken(nbytes int) string {
	b := make([]byte, nbytes)
	if _, err := rand.Read(b); err != nil {
		panic(err) // crypto/rand does not fail on supported platforms
	}
	return b32.EncodeToString(b)
}

// GenerateName returns "<backend>-<6 random base32 chars>".
func GenerateName(backend string) string { return backend + "-" + randToken(4)[:6] }

// NewMarker returns the per-generation process marker "<name>:<gen>:<nonce>".
func NewMarker(name string, gen int) string {
	return name + ":" + strconv.Itoa(gen) + ":" + randToken(10)
}

// WriteJSON writes v atomically (temp file in the same dir, fsync, rename).
func WriteJSON(path string, v any) error {
	b, err := json.MarshalIndent(v, "", "  ")
	if err != nil {
		return err
	}
	return WriteFileAtomic(path, append(b, '\n'), 0o600)
}

func WriteFileAtomic(path string, data []byte, perm fs.FileMode) error {
	f, err := os.CreateTemp(filepath.Dir(path), "."+filepath.Base(path)+".tmp-*")
	if err != nil {
		return err
	}
	tmp := f.Name()
	defer os.Remove(tmp) // no-op after a successful rename
	if _, err := f.Write(data); err != nil {
		f.Close()
		return err
	}
	if err := f.Chmod(perm); err != nil {
		f.Close()
		return err
	}
	if err := f.Sync(); err != nil {
		f.Close()
		return err
	}
	if err := f.Close(); err != nil {
		return err
	}
	return os.Rename(tmp, path)
}

func ReadJSON(path string, v any) error {
	b, err := os.ReadFile(path)
	if err != nil {
		return err
	}
	return json.Unmarshal(b, v)
}
```

```go
// View is a session as read from disk, with its effective state resolved
// against live process state.
type View struct {
	Dir      Dir
	Session  Session
	Status   Status
	Plan     *Plan
	Launcher *LauncherRecord
	State    string          // effective: may be "lost" although status.json says otherwise
	Orphans  []proc.Identity // marked processes still alive in a lost session
}

// Load reads a session. handshake is the configured handshake timeout; a
// starting session with no monitor record is lost once older than 2×handshake.
func Load(name string, handshake time.Duration) (*View, error) {
	if !ValidName(name) {
		return nil, fmt.Errorf("%w: %q", ErrNotFound, name)
	}
	d := DirFor(name)
	if _, err := os.Stat(string(d)); errors.Is(err, fs.ErrNotExist) {
		return nil, fmt.Errorf("%w: %s", ErrNotFound, name)
	}
	v := &View{Dir: d}
	if err := ReadJSON(d.SessionPath(), &v.Session); err != nil {
		return nil, fmt.Errorf("%s: %w", name, err)
	}
	if err := ReadJSON(d.StatusPath(), &v.Status); err != nil {
		return nil, fmt.Errorf("%s: %w", name, err)
	}
	gen := v.Generation()
	var p Plan
	if ReadJSON(d.PlanPath(gen), &p) == nil {
		v.Plan = &p
	}
	var l LauncherRecord
	if ReadJSON(d.LauncherPath(gen), &l) == nil {
		v.Launcher = &l
	}
	v.resolve(handshake, time.Now())
	return v, nil
}

// Generation is the current generation (1 if status predates the field).
func (v *View) Generation() int {
	if v.Status.Generation > 0 {
		return v.Status.Generation
	}
	return 1
}

// MonitorIdentity returns the best-known monitor identity: from status.json,
// else from the launcher record.
func (v *View) MonitorIdentity() (proc.Identity, string, bool) {
	if v.Status.Monitor != nil {
		return *v.Status.Monitor, v.Status.BootID, true
	}
	if v.Launcher != nil && v.Launcher.Monitor != nil {
		return *v.Launcher.Monitor, v.Launcher.BootID, true
	}
	return proc.Identity{}, "", false
}

// Alive reports whether the session is still being supervised.
func (v *View) Alive() bool { return v.State == StateRunning || v.State == StateStarting }

func (v *View) resolve(handshake time.Duration, now time.Time) {
	v.State = v.Status.State
	if v.State == StateRunning || v.State == StateStarting {
		id, boot, ok := v.MonitorIdentity()
		switch {
		case ok && proc.MaybeAlive(id, boot):
			// still supervised (or liveness unknown: never declare lost on a read error)
		case !ok && v.State == StateStarting && now.Sub(v.Session.CreatedAt) < 2*handshake:
			// launcher record not written yet; give it time
		default:
			v.State = StateLost
		}
	}
	if v.State == StateLost && v.Plan != nil {
		v.Orphans, _ = proc.FindMarked(v.Status.PGID, v.Plan.Marker, v.Status.BootID)
	}
}
```

```go
package session

import (
	"os"
	"syscall"
	"time"
)

// Finalize lets the CLI complete status.json for a session whose monitor is
// confirmed dead. It holds an exclusive flock on the session's lock file,
// re-reads status.json, and leaves an already-exited record untouched, so a
// record the monitor wrote just before dying is never overwritten and two
// CLIs never finalize at once. It reports whether it wrote.
func Finalize(d Dir, mutate func(*Status)) (bool, error) {
	f, err := os.OpenFile(d.LockPath(), os.O_CREATE|os.O_RDWR, 0o600)
	if err != nil {
		return false, err
	}
	defer f.Close()
	if err := syscall.Flock(int(f.Fd()), syscall.LOCK_EX); err != nil {
		return false, err
	}
	defer syscall.Flock(int(f.Fd()), syscall.LOCK_UN)

	var st Status
	if err := ReadJSON(d.StatusPath(), &st); err != nil {
		return false, err
	}
	if st.State == StateExited {
		return false, nil
	}
	mutate(&st)
	st.SchemaVersion = SchemaVersion
	st.UpdatedAt = time.Now().UTC()
	return true, WriteJSON(d.StatusPath(), &st)
}
```

```go
	Command       string              `toml:"command"`
	Headless      Headless            `toml:"headless"`
	Options       map[string][]string `toml:"options"`
	Permissions   map[string][]string `toml:"permissions"`

	Check         Check               `toml:"check"`

	Source string `toml:"-"` // "builtin" or the file path
	SHA256 string `toml:"-"` // of the file's bytes
}

type Headless struct {

	Prompt string   `toml:"prompt"` // "stdin" | "arg"

}

	Args []string `toml:"args"`

type Check struct {
	VersionArgs []string    `toml:"version_args"`
	Diagnose    []Diagnosis `toml:"diagnose"`
}

type Diagnosis struct {
	Match string `toml:"match"`
	Hint  string `toml:"hint"`
}

// Load resolves name: <userDir>/<name>.toml, else the embedded built-in.
func Load(name, userDir string) (*Profile, error) {
	if !nameRE.MatchString(name) {
		return nil, fmt.Errorf("%w: %q", ErrUnknownBackend, name)
	}
	var data []byte
	var source string
	if userDir != "" {
		path := filepath.Join(userDir, name+".toml")
		b, err := os.ReadFile(path)
		switch {
		case err == nil:
			data, source = b, path
		case !errors.Is(err, fs.ErrNotExist):
			return nil, err
		}
	}
	if data == nil {
		b, err := builtin.ReadFile("profiles/" + name + ".toml")
		if err != nil {
			return nil, fmt.Errorf("%w: %q", ErrUnknownBackend, name)
		}
		data, source = b, "builtin"
	}
	p, err := Parse(data)
	if err != nil {
		return nil, fmt.Errorf("backend %s (%s): %w", name, source, err)
	}
	if p.Name != name {
		return nil, fmt.Errorf("backend %s (%s): name field is %q", name, source, p.Name)
	}
	sum := sha256.Sum256(data)
	p.Source, p.SHA256 = source, hex.EncodeToString(sum[:])
	return p, nil
}

// Parse decodes and validates profile TOML. Unknown keys are errors.
func Parse(data []byte) (*Profile, error) {
	var p Profile
	md, err := toml.Decode(string(data), &p)
	if err != nil {
		return nil, err
	}
	if und := md.Undecoded(); len(und) > 0 {
		keys := make([]string, len(und))
		for i, k := range und {
			keys[i] = k.String()
		}
		return nil, fmt.Errorf("unknown keys: %s", strings.Join(keys, ", "))
	}
	return &p, p.validate()
}

func (p *Profile) validate() error {
	if p.SchemaVersion != 1 {
		return fmt.Errorf("schema_version %d not supported (want 1)", p.SchemaVersion)
	}
	if p.Name == "" || p.Command == "" {
		return errors.New("name and command are required")
	}
	if p.Headless.Prompt != "stdin" && p.Headless.Prompt != "arg" {
		return fmt.Errorf("headless.prompt %q: want \"stdin\" or \"arg\"", p.Headless.Prompt)
	}
	if _, ok := parser.Get(p.Headless.Parser); !ok {
		return fmt.Errorf("headless.parser %q unknown (known: %s)", p.Headless.Parser, strings.Join(parser.Names(), ", "))
	}
	if len(p.Permissions) == 0 {
		return errors.New("[permissions] must define at least one level")
	}
	for lvl := range p.Permissions {
		if !levels[lvl] {
			return fmt.Errorf("permissions.%s: unknown level (known: auto, skip)", lvl)
		}
	}
	for opt := range p.Options {
		if !options[opt] {
			return fmt.Errorf("options.%s: unknown option (known: model)", opt)
		}
	}
	for i, d := range p.Check.Diagnose {
		if _, err := regexp.Compile(d.Match); err != nil {
			return fmt.Errorf("check.diagnose[%d].match: %w", i, err)
		}
		if d.Hint == "" {
			return fmt.Errorf("check.diagnose[%d].hint is required", i)
		}
	}
	return nil
}

// Levels lists the permission levels a profile defines, sorted.
func (p *Profile) Levels() []string {
	out := make([]string, 0, len(p.Permissions))
	for l := range p.Permissions {
		out = append(out, l)
	}
	sort.Strings(out)
	return out
}

// Names lists every resolvable backend: built-ins plus user files, sorted.
func Names(userDir string) ([]string, error) {
	set := map[string]bool{}
	ents, err := builtin.ReadDir("profiles")
	if err != nil {
		return nil, err
	}
	for _, e := range ents {
		set[strings.TrimSuffix(e.Name(), ".toml")] = true
	}
	if userDir != "" {
		files, err := os.ReadDir(userDir)
		if err != nil && !errors.Is(err, fs.ErrNotExist) {
			return nil, err
		}
		for _, f := range files {
			if n := strings.TrimSuffix(f.Name(), ".toml"); n != f.Name() && nameRE.MatchString(n) {
				set[n] = true
			}
		}
	}
	out := make([]string, 0, len(set))
	for n := range set {
		out = append(out, n)
	}
	sort.Strings(out)
	return out, nil
}
```

```go
	}
```

```go
// Package monitor is the body of the hidden `fastener _monitor` command: one
// monitor per session generation. It spawns the agent from the launch plan,
// records output and parser fields, enforces limits, turns signals into
// recorded facts, and is the only writer of status.json while it lives.
package monitor

import (
	"bufio"
	"bytes"
	"fmt"
	"log"
	"os"
	"os/exec"
	"os/signal"
	"runtime"
	"sync"
	"syscall"
	"time"
	"unicode/utf8"

	"golang.org/x/sys/unix"

	"github.com/ytjohn/fastener/internal/parser"
	"github.com/ytjohn/fastener/internal/proc"
	"github.com/ytjohn/fastener/internal/runenv"
	"github.com/ytjohn/fastener/internal/session"

// drainTimeout bounds how long the monitor waits for stdout EOF after the
// agent exits; a grandchild may hold the pipe open indefinitely.
const drainTimeout = 2 * time.Second

// Lines longer than maxParseLine are logged but not parsed (counted as parse
// errors), so a huge tool result is never unmarshalled while holding m.mu.
// (ReadBytes still allocates the whole line; this caps parsing, not memory.)
// final_message is capped so status.json stays small.
const (
	maxParseLine    = 16 << 20
	maxFinalMessage = 64 << 10
)

type monitor struct {
	d    session.Dir
	gen  int
	sess session.Session
	plan session.Plan
	log  *log.Logger

	mu    sync.Mutex
	st    session.Status
	dirty bool
}

// Run executes one generation. It returns a process exit code for the
// monitor itself (0 whenever an outcome was recorded).
func Run(dir string, gen int, logger *log.Logger) int {
	// Subscribe before anything else so a stop during startup is not lost.
	sigs := make(chan os.Signal, 4)
	signal.Notify(sigs, syscall.SIGTERM, syscall.SIGINT, syscall.SIGHUP)

	m, err := load(session.Dir(dir), gen, logger)
	if err != nil {
		logger.Printf("cannot start: %v", err)
		return 1
	}
	return m.run(sigs)
}

func load(d session.Dir, gen int, logger *log.Logger) (*monitor, error) {
	m := &monitor{d: d, gen: gen, log: logger}
	if err := session.ReadJSON(d.SessionPath(), &m.sess); err != nil {
		return nil, err
	}
	if err := session.ReadJSON(d.PlanPath(gen), &m.plan); err != nil {
		return nil, err
	}
	if err := session.ReadJSON(d.StatusPath(), &m.st); err != nil {
		return nil, err
	}
	if len(m.plan.Argv) == 0 {
		return nil, fmt.Errorf("plan %d has empty argv", gen)
	}
	boot, err := proc.BootID()
	if err != nil {
		return nil, err
	}
	self, err := proc.Self()
	if err != nil {
		return nil, err
	}
	m.st.Generation, m.st.Monitor, m.st.BootID = gen, &self, boot
	return m, nil
}

// write persists status; callers hold m.mu.
func (m *monitor) write() {
	m.st.SchemaVersion = session.SchemaVersion
	m.st.UpdatedAt = time.Now().UTC()
	if err := session.WriteJSON(m.d.StatusPath(), &m.st); err != nil {
		m.log.Printf("write status: %v", err)
	}
	m.dirty = false
}

func (m *monitor) finish(endedBy string, mutate func(*session.Status)) {
	m.mu.Lock()
	defer m.mu.Unlock()
	now := time.Now().UTC()
	m.st.State, m.st.EndedBy, m.st.EndedAt = session.StateExited, endedBy, &now
	if mutate != nil {
		mutate(&m.st)
	}
	m.write()
}

// stopRequest reports a stop request addressed to this generation.
func (m *monitor) stopRequest() (session.StopRequest, bool) {
	var r session.StopRequest
	if err := session.ReadJSON(m.d.StopPath(), &r); err != nil {
		return r, false
	}
	return r, r.Generation == m.gen
}

func (m *monitor) agentEnv() ([]string, error) {
	layers := [][]string{m.sess.EnvBase}
	if m.sess.EnvFile != "" {
		f, err := runenv.ReadFile(m.sess.EnvFile)
		if err != nil {
			return nil, fmt.Errorf("env file: %w", err)
		}
		layers = append(layers, f)
	}
	layers = append(layers, m.sess.Env, []string{proc.MarkerEnv + "=" + m.plan.Marker})
	return runenv.Merge(layers...), nil
}

func (m *monitor) launchFailed(err error) int {
	m.finish(session.EndedByLaunchFailed, func(s *session.Status) { s.Error = err.Error() })
	return 0
}

func (m *monitor) run(sigs <-chan os.Signal) int {
	if _, ok := m.stopRequest(); ok {
		m.finish(session.EndedByStop, nil) // stopped before the agent was spawned
		return 0
	}
	env, err := m.agentEnv()
	if err != nil {
		return m.launchFailed(err)
	}
	out, err := os.OpenFile(m.d.OutputLog(), os.O_CREATE|os.O_WRONLY|os.O_APPEND, 0o600)
	if err != nil {
		return m.launchFailed(err)
	}
	defer out.Close()
	errLog, err := os.OpenFile(m.d.StderrLog(), os.O_CREATE|os.O_WRONLY|os.O_APPEND, 0o600)
	if err != nil {
		return m.launchFailed(err)
	}
	defer errLog.Close()

	cmd := exec.Command(m.plan.Argv[0], m.plan.Argv[1:]...)
	cmd.Dir = m.sess.Cwd
	cmd.Env = env
	cmd.Stderr = errLog
	cmd.SysProcAttr = agentSysProcAttr()
	if m.plan.PromptMode == "stdin" {
		in, err := os.Open(m.d.PromptPath())
		if err != nil {
			return m.launchFailed(err)
		}
		defer in.Close()
		cmd.Stdin = in
	}
	pr, pw, err := os.Pipe()
	if err != nil {
		return m.launchFailed(err)
	}
	cmd.Stdout = pw

	// Linux delivers Pdeathsig when the spawning *thread* exits (golang/go#27505),
	// so spawn and wait on one locked thread that lives as long as the agent.
	started := make(chan error, 1)
	exited := make(chan *os.ProcessState, 1)
	go func() {
		runtime.LockOSThread() // never unlocked: the thread exits with the goroutine
		if err := cmd.Start(); err != nil {
			started <- err
			return
		}
		started <- nil
		_ = cmd.Wait()
		exited <- cmd.ProcessState
	}()
	if err := <-started; err != nil {
		pw.Close()
		pr.Close()
		return m.launchFailed(err)
	}
	pw.Close() // the agent holds the write end now

	pid := cmd.Process.Pid
	agent, err := proc.Of(pid)
	if err != nil {
		agent = proc.Identity{PID: pid} // already exited; exit facts follow
	}
	m.mu.Lock()
	now := time.Now().UTC()
	m.st.State, m.st.Agent, m.st.PGID, m.st.StartedAt = session.StateRunning, &agent, pid, &now
	m.write()
	m.mu.Unlock()

	p, ok := parser.Get(m.plan.Parser)
	if !ok {
		p, _ = parser.Get("none")
	}
	drained := make(chan struct{})
	go m.pump(pr, out, p, drained)
	stopFlush := make(chan struct{})
	go m.flushLoop(stopFlush)

	var limit <-chan time.Time
	if m.sess.MaxRuntime > 0 {
		t := time.NewTimer(time.Duration(m.sess.MaxRuntime))
		defer t.Stop()
		limit = t.C
	}

	endedBy := session.EndedByExit
	var ps *os.ProcessState
	select {
	case ps = <-exited:
	case <-limit:
		endedBy = session.EndedByLimit
		ps = terminate(pid, time.Duration(m.sess.Grace), exited)
	case sig := <-sigs:
		grace := time.Duration(m.sess.Grace)
		endedBy = session.EndedBySignal
		if req, ok := m.stopRequest(); ok {
			endedBy = session.EndedByStop
			if req.Grace > 0 {
				grace = time.Duration(req.Grace)
			}
		}
		m.log.Printf("received %v; ended_by=%s grace=%s", sig, endedBy, grace)
		ps = terminate(pid, grace, exited)
	}

	select {
	case <-drained:
	case <-time.After(drainTimeout):
		m.log.Printf("stdout still open after agent exit (a descendant holds it); not waiting")
	}
	close(stopFlush)
	m.finish(endedBy, func(s *session.Status) { exitFacts(s, ps) })
	return 0
}

// terminate sends SIGTERM to the agent's process group, waits up to grace for
// the agent to exit, then SIGKILLs the group (reaching any lingering members).
func terminate(pgid int, grace time.Duration, exited <-chan *os.ProcessState) *os.ProcessState {
	_ = syscall.Kill(-pgid, syscall.SIGTERM)
	var ps *os.ProcessState
	select {
	case ps = <-exited:
	case <-time.After(grace):
	}
	_ = syscall.Kill(-pgid, syscall.SIGKILL)
	if ps == nil {
		ps = <-exited
	}
	return ps
}

func exitFacts(s *session.Status, ps *os.ProcessState) {
	if ps == nil {
		return
	}
	if ws, ok := ps.Sys().(syscall.WaitStatus); ok && ws.Signaled() {
		s.Signal = unix.SignalName(ws.Signal())
		return
	}
	code := ps.ExitCode()
	s.ExitCode = &code
}

// pump copies agent stdout to output.log unchanged and feeds the parser.
func (m *monitor) pump(r *os.File, out *os.File, p parser.Parser, done chan<- struct{}) {
	defer close(done)
	defer r.Close()
	br := bufio.NewReaderSize(r, 64*1024)
	for {
		line, err := br.ReadBytes('\n')
		if len(line) > 0 {
			_, _ = out.Write(line)
			m.mu.Lock()
			switch {
			case len(line) > maxParseLine:
				m.st.ParseErrors++
				m.dirty = true
			case p.Line(bytes.TrimRight(line, "\r\n"), &m.st.Fields):
				if len(m.st.FinalMessage) > maxFinalMessage {
					i := maxFinalMessage
					for i > 0 && !utf8.RuneStart(m.st.FinalMessage[i]) {
						i-- // never split a UTF-8 sequence
					}
					m.st.FinalMessage = m.st.FinalMessage[:i]
				}
				m.dirty = true
			}
			m.mu.Unlock()
		}
		if err != nil {
			return
		}
	}
}

// flushLoop writes parser updates at most once per second.
func (m *monitor) flushLoop(stop <-chan struct{}) {
	t := time.NewTicker(time.Second)
	defer t.Stop()
	for {
		select {
		case <-stop:
			return
		case <-t.C:
			m.mu.Lock()
			if m.dirty {
				m.write()
			}
			m.mu.Unlock()
		}
	}
}
```

```go
}

// Setsid re-executes this binary as `_monitor` in a new session, with stdio
// to monitor.log, and releases it without waiting. Go cannot fork without
// exec, so there is no double fork; the CLI knows the monitor pid directly.
type Setsid struct{}

func (Setsid) Name() string { return "setsid" }

func (Setsid) Start(d session.Dir, gen int) (session.LauncherRecord, error) {
	exe, err := os.Executable()
	if err != nil {
		return session.LauncherRecord{}, err
	}
	logf, err := os.OpenFile(d.MonitorLog(), os.O_CREATE|os.O_WRONLY|os.O_APPEND, 0o600)
	if err != nil {
		return session.LauncherRecord{}, err
	}
	defer logf.Close()
	cmd := exec.Command(exe, "_monitor", string(d), strconv.Itoa(gen))
	cmd.Dir = "/"
	cmd.Stdout, cmd.Stderr = logf, logf
	cmd.SysProcAttr = &syscall.SysProcAttr{Setsid: true}
	if err := cmd.Start(); err != nil {
		return session.LauncherRecord{}, err
	}
	id, err := proc.Of(cmd.Process.Pid)
	if err != nil {
		id = proc.Identity{PID: cmd.Process.Pid} // already gone; its status says why
	}
	boot, _ := proc.BootID()
	_ = cmd.Process.Release()
	return session.LauncherRecord{
		SchemaVersion: session.SchemaVersion, Launcher: "setsid",
		Monitor: &id, BootID: boot, LaunchedAt: time.Now().UTC(),
	}, nil
}
```

```go
func runMonitor(args []string, stderr io.Writer) int {
	if len(args) != 2 {
		return exitUsage
	}
	gen, err := strconv.Atoi(args[1])

		return exitUsage

type usageError struct{ msg string }

func (e usageError) Error() string { return e.msg }

func usagef(format string, a ...any) error { return usageError{fmt.Sprintf(format, a...)} }

// fail prints err and maps it to an exit code.
func fail(stderr io.Writer, err error) int {
	fmt.Fprintf(stderr, "fastener: %v\n", err)
	var ue usageError
	switch {
	case errors.As(err, &ue):
		return exitUsage
	case errors.Is(err, profile.ErrUnknownBackend), errors.Is(err, session.ErrNotFound):
		return exitNotFound
	}
	return exitFail
}
```

```go
import (

type multiFlag []string

func (m *multiFlag) String() string     { return strings.Join(*m, ",") }
func (m *multiFlag) Set(v string) error { *m = append(*m, v); return nil }

func newFlagSet(name string, stderr io.Writer) *flag.FlagSet {
	fs := flag.NewFlagSet("fastener "+name, flag.ContinueOnError)
	fs.SetOutput(stderr)
	return fs
}

// parseArgs lets flags and positional arguments interleave
// ("run claude --cwd x" and "run --cwd x claude" both work).
func parseArgs(fs *flag.FlagSet, args []string) ([]string, error) {
	var pos []string
	for {
		if err := fs.Parse(args); err != nil {
			return nil, err
		}
		rest := fs.Args()
		if len(rest) == 0 {
			return pos, nil
		}
		pos = append(pos, rest[0])
		args = rest[1:]
	}
}

func parseLabels(items []string) (map[string]string, error) {
	if len(items) == 0 {
		return nil, nil
	}
	out := map[string]string{}
	for _, it := range items {
		k, v, ok := strings.Cut(it, "=")
		if !ok || k == "" {
			return nil, usagef("--label %q: want KEY=VALUE", it)
		}
		out[k] = v
	}
	return out, nil
}

func writeJSON(w io.Writer, v any) {
	enc := json.NewEncoder(w)
	enc.SetIndent("", "  ")
	_ = enc.Encode(v)
}
```

```go
	Permissions, Model                 string

	Env                                []string

// stepError tags a pre-flight error with the `check` step it belongs to.
type stepError struct {
	step string
	err  error
}

func (e *stepError) Error() string { return e.err.Error() }
func (e *stepError) Unwrap() error { return e.err }

func inStep(step string, err error) error { return &stepError{step: step, err: err} }

// prepared is everything resolved before a session directory exists.
type prepared struct {
	cfg      config.Config
	prof     *profile.Profile
	perms    string
	rendered profile.Rendered
	argv0    string
	envBase  []string
	envFile  string
	fileEnv  []string
	launcher launcher.Launcher
}

func (p *prepared) mergedEnv(extra []string) []string {
	return runenv.Merge(p.envBase, p.fileEnv, extra)
}

// prepare runs every check that can fail without side effects.
func prepare(o launchOptions, prompt string) (*prepared, error) {
	cfg, err := config.Load()
	if err != nil {
		return nil, inStep("profile", err)
	}
	prof, err := profile.Load(o.Backend, config.BackendsDir())
	if err != nil {
		return nil, inStep("profile", err)
	}
	perms := o.Permissions
	if perms == "" {
		perms = cfg.DefaultPermissions
	}
	if perms == "" {
		perms = "auto"
	}
	r, err := prof.RenderHeadless(profile.Request{Permissions: perms, Model: o.Model, Prompt: prompt})
	if err != nil {
		return nil, inStep("profile", err)
	}
	for _, kv := range o.Env {
		if k, _, ok := strings.Cut(kv, "="); !ok || k == "" {
			return nil, inStep("binary", usagef("--env %q: want KEY=VALUE", kv))
		}
	}
	p := &prepared{cfg: cfg, prof: prof, perms: perms, rendered: r}
	p.envBase = runenv.Base(cfg.EnvPassthrough, os.Environ())
	if o.EnvFile != "" {
		abs, err := filepath.Abs(o.EnvFile)
		if err != nil {
			return nil, inStep("binary", err)
		}
		if p.fileEnv, err = runenv.ReadFile(abs); err != nil {
			return nil, inStep("binary", fmt.Errorf("--env-file: %w", err))
		}
		p.envFile = abs
	}
	p.argv0, err = runenv.LookPath(prof.Command, runenv.Get(p.mergedEnv(o.Env), "PATH"))
	if err != nil {
		return nil, inStep("binary", err)
	}
	pref := o.Launcher
	if pref == "" {
		pref = cfg.Launcher
	}
	if p.launcher, err = launcher.Select(pref); err != nil {
		return nil, inStep("launch", err)
	}
	return p, nil
}

// launch creates a session and starts its monitor. On a handshake failure it
// returns the view (if one exists) together with the error.
func launch(o launchOptions) (*session.View, error) {
	prompt, source := o.Prompt, "inline"
	if o.PromptFile != "" {
		if prompt != "" {
			return nil, usagef("--prompt and --prompt-file are mutually exclusive")
		}
		abs, err := filepath.Abs(o.PromptFile)
		if err != nil {
			return nil, err
		}
		b, err := os.ReadFile(abs)
		if err != nil {
			return nil, err
		}
		prompt, source = string(b), abs
	}
	if strings.TrimSpace(prompt) == "" {
		return nil, usagef("a prompt is required (--prompt or --prompt-file)")
	}
	if o.Cwd == "" {
		return nil, usagef("--cwd is required")
	}
	cwd, err := filepath.Abs(o.Cwd)
	if err != nil {
		return nil, err
	}
	if o.Name != "" && !session.ValidName(o.Name) {
		return nil, usagef("invalid --name %q", o.Name)
	}
	p, err := prepare(o, prompt)
	if err != nil {
		return nil, err
	}
	name := o.Name
	if name == "" {
		name = session.GenerateName(o.Backend)
	}
	d, err := session.Create(name)
	if err != nil {
		return nil, inStep("launch", err)
	}
	now := time.Now().UTC()
	sess := session.Session{
		SchemaVersion: session.SchemaVersion, Name: name, CreatedAt: now, Kind: "headless",
		Backend: o.Backend, Cwd: cwd, PromptSource: source, Permissions: p.perms, Model: o.Model,
		MaxRuntime: session.Duration(o.MaxRuntime), Grace: session.Duration(o.Grace),
		EnvBase: p.envBase, Env: o.Env, EnvFile: p.envFile, Labels: o.Labels, Restart: "no",
	}
	plan := session.Plan{
		SchemaVersion: session.SchemaVersion, Generation: 1,
		Argv: append([]string{p.argv0}, p.rendered.Args...), PromptMode: p.rendered.PromptMode,
		Parser: p.rendered.Parser, ProfileSource: p.prof.Source, ProfileSHA256: p.prof.SHA256,
		Marker: session.NewMarker(name, 1), FastenerVersion: version.Version, PlannedAt: now,
	}
	writes := []struct {
		path string
		v    any
	}{
		{d.SessionPath(), sess},
		{d.PlanPath(1), plan},
		{d.StatusPath(), session.Status{SchemaVersion: session.SchemaVersion, State: session.StateStarting, Generation: 1, UpdatedAt: now}},
	}
	if err := session.WriteFileAtomic(d.PromptPath(), []byte(prompt), 0o600); err != nil {
		return nil, inStep("launch", err)
	}
	for _, w := range writes {
		if err := session.WriteJSON(w.path, w.v); err != nil {
			return nil, inStep("launch", err)
		}
	}
	rec, err := p.launcher.Start(d, 1)
	if err != nil {
		_, _ = session.Finalize(d, func(s *session.Status) {
			t := time.Now().UTC()
			s.State, s.EndedBy, s.EndedAt, s.Error = session.StateExited, session.EndedByLaunchFailed, &t, "monitor: "+err.Error()
		})
		return nil, inStep("launch", fmt.Errorf("start monitor: %w", err))
	}
	if err := session.WriteJSON(d.LauncherPath(1), rec); err != nil {
		return nil, inStep("launch", err)
	}
	return handshake(name, p.cfg.Handshake())
}

func handshake(name string, timeout time.Duration) (*session.View, error) {
	deadline := time.Now().Add(timeout)
	for {
		v, err := session.Load(name, timeout)
		if err != nil {
			return nil, inStep("launch", err)
		}
		switch v.State {
		case session.StateRunning:
			return v, nil
		case session.StateExited:
			if v.Status.EndedBy == session.EndedByLaunchFailed {
				return v, inStep("launch", fmt.Errorf("launch failed: %s", v.Status.Error))
			}
			return v, nil // a fast agent may already have finished
		case session.StateLost:
			return v, inStep("launch", fmt.Errorf("monitor died during launch; see %s", v.Dir.MonitorLog()))
		}
		if time.Now().After(deadline) {
			return v, inStep("launch", fmt.Errorf("session %s did not start within %s; see %s", name, timeout, v.Dir.MonitorLog()))
		}
		time.Sleep(25 * time.Millisecond)
	}
}
```

```go
	tw.Flush()
	return exitOK

	if len(s) <= n {
		return s
	}

func cmdPs(args []string, stdout, stderr io.Writer) int {
	fs := newFlagSet("ps", stderr)
	all := fs.Bool("all", false, "include everything retained, not just recent")
	asJSON := fs.Bool("json", false, "print JSON")

		return exitUsage
	}
	names, err := session.Names()
	if err != nil {
		return fail(stderr, err)
	}
	hs := handshakeTimeout()
	cutoff := time.Now().Add(-24 * time.Hour)
	rows := []psRow{}
	for _, n := range names {
		v, err := session.Load(n, hs)
		if err != nil {
			fmt.Fprintf(stderr, "fastener: skipping %s: %v\n", n, err)
			continue
		}
		recent := v.Alive() || v.State == session.StateLost ||
			(v.Status.EndedAt != nil && v.Status.EndedAt.After(cutoff)) ||
			(v.Status.EndedAt == nil && v.Session.CreatedAt.After(cutoff))

			continue
		}
		rows = append(rows, psRow{
			Name: n, Backend: v.Session.Backend, State: v.State, CreatedAt: v.Session.CreatedAt,
			EndedAt: v.Status.EndedAt, EndedBy: v.Status.EndedBy, ExitCode: v.Status.ExitCode,
			Orphans: len(v.Orphans), Labels: v.Session.Labels,
		})
	}
	sort.Slice(rows, func(i, j int) bool { return rows[i].CreatedAt.After(rows[j].CreatedAt) })
	if *asJSON {
		writeJSON(stdout, rows)
		return exitOK
	}
	tw := tabwriter.NewWriter(stdout, 0, 2, 2, ' ', 0)
	fmt.Fprintln(tw, "NAME\tBACKEND\tSTATE\tAGE\tENDED_BY\tEXIT")
	for _, r := range rows {
		exit := ""
		if r.ExitCode != nil {
			exit = fmt.Sprint(*r.ExitCode)
		}
		fmt.Fprintf(tw, "%s\t%s\t%s\t%s\t%s\t%s\n", r.Name, r.Backend, r.State,
			time.Since(r.CreatedAt).Round(time.Second), r.EndedBy, exit)
	}

	return exitOK
```

```go
	return exitOK

// followLog copies path to stdout until the session is no longer alive.
func followLog(name, path string, stdout, stderr io.Writer) int {
	var f *os.File
	defer func() {
		if f != nil {
			f.Close()
		}
	}()
	for {
		if f == nil {
			if g, err := os.Open(path); err == nil {
				f = g
			}
		}
		if f != nil {
			_, _ = io.Copy(stdout, f)
		}
		v, err := loadView(name)
		if err != nil {
			return fail(stderr, err)
		}
		if !v.Alive() {
			if f != nil {
				_, _ = io.Copy(stdout, f)
			}
			return exitOK
		}
		time.Sleep(200 * time.Millisecond)
	}
```

```go
func cmdWait(args []string, stdout, stderr io.Writer) int {
	fs := newFlagSet("wait <name>", stderr)
	timeout := fs.Duration("timeout", 0, "give up after this long (exit 124)")
	pos, err := parseArgs(fs, args)
	if err != nil {
		return exitUsage
	}
	name, ok := oneName(pos, stderr, "wait <name> [--timeout D]")
	if !ok {
		return exitUsage
	}
	var deadline time.Time
	if *timeout > 0 {
		deadline = time.Now().Add(*timeout)
	}
	for {
		v, err := loadView(name)
		if err != nil {
			return fail(stderr, err)
		}
		switch v.State {
		case session.StateExited:
			return exitCodeOf(v.Status)
		case session.StateLost, session.StateRestoreFailed:
			fmt.Fprintf(stderr, "fastener: session %s is %s\n", name, v.State)
			return exitAbnormal
		}
		if !deadline.IsZero() && time.Now().After(deadline) {
			return exitWaitTimeout
		}
		time.Sleep(200 * time.Millisecond)
	}
}

// exitCodeOf maps an exited status to wait's exit code (spec §10).
func exitCodeOf(s session.Status) int {
	if s.EndedBy == session.EndedByLaunchFailed {
		return exitAbnormal
	}
	if s.Signal != "" {
		if n := int(unix.SignalNum(s.Signal)); n > 0 {
			return 128 + n
		}
		return exitAbnormal
	}
	if s.ExitCode != nil {
		return *s.ExitCode
	}
	return exitAbnormal
}
```

```go
func cmdRm(args []string, stdout, stderr io.Writer) int {
	fs := newFlagSet("rm <name>", stderr)
	force := fs.Bool("force", false, "stop the session first if it is alive or has orphans")
	pos, err := parseArgs(fs, args)
	if err != nil {
		return exitUsage
	}
	name, ok := oneName(pos, stderr, "rm <name> [--force]")
	if !ok {

	}
	v, err := loadView(name)
	if err != nil {
		return fail(stderr, err)
	}
	if v.Alive() || len(v.Orphans) > 0 {
		if !*force {
			return fail(stderr, fmt.Errorf("session %s is %s (orphans: %d); stop it first or use --force", name, v.State, len(v.Orphans)))
		}
		if err := stopSession(v, 0, "rm"); err != nil {
			return fail(stderr, err)
		}
	}
	if err := os.RemoveAll(string(v.Dir)); err != nil {
		return fail(stderr, err)
	}
	return exitOK
}

// stopSession stops a session through its monitor, or, for a lost session,
// signals each verified orphan and finalizes status.json.
func stopSession(v *session.View, grace time.Duration, by string) error {
	if grace <= 0 {
		grace = time.Duration(v.Session.Grace)
	}
	if grace <= 0 {
		grace = 10 * time.Second
	}
	switch {
	case v.State == session.StateExited || v.State == session.StateRestoreFailed:
		return nil
	case v.Alive():
		req := session.StopRequest{
			SchemaVersion: session.SchemaVersion, Generation: v.Generation(),
			RequestedAt: time.Now().UTC(), Grace: session.Duration(grace), By: by,
		}
		if err := session.WriteJSON(v.Dir.StopPath(), req); err != nil {
			return err
		}
		if id, boot, ok := v.MonitorIdentity(); ok {
			if err := proc.Signal(id, boot, syscall.SIGTERM); err != nil && !errors.Is(err, proc.ErrNoProcess) {
				return err
			}
		} // else: the monitor has not started yet and will honour the request on start
		return waitStopped(v.Session.Name, grace+2*handshakeTimeout()+10*time.Second, grace, by)
	case v.State == session.StateLost:
		if len(v.Orphans) > 0 {
			killOrphans(v.Orphans, v.Status.BootID, grace)
		}
		_, err := session.Finalize(v.Dir, func(s *session.Status) {
			now := time.Now().UTC()
			s.State, s.EndedBy, s.EndedAt = session.StateExited, session.EndedByStop, &now
			if s.Error == "" {
				s.Error = "monitor was lost; finalized by " + by
			}
		})
		return err
	}
	return fmt.Errorf("session %s in unexpected state %q", v.Session.Name, v.State)
}

func waitStopped(name string, timeout, grace time.Duration, by string) error {
	deadline := time.Now().Add(timeout)
	for {
		v, err := loadView(name)
		if err != nil {
			return err
		}
		switch v.State {
		case session.StateExited:
			return nil
		case session.StateLost: // the monitor died mid-stop: clean up directly
			return stopSession(v, grace, by)
		}
		if time.Now().After(deadline) {
			return fmt.Errorf("session %s did not stop within %s; see %s", name, timeout, v.Dir.MonitorLog())
		}
		time.Sleep(50 * time.Millisecond)
	}
}

// killOrphans signals each identified pid (never the pgid as a whole).
func killOrphans(ids []proc.Identity, boot string, grace time.Duration) {
	for _, id := range ids {
		_ = proc.Signal(id, boot, syscall.SIGTERM)
	}
	left := proc.WaitGone(ids, boot, grace)
	for _, id := range left {
		_ = proc.Signal(id, boot, syscall.SIGKILL)
	}
	proc.WaitGone(left, boot, 2*time.Second)
}
```

```go
const (
	checkPrompt  = "Reply with exactly one word: pong"
	timeoutHint  = "timed out: the agent may be waiting for interactive input (for example a login prompt)"
	stepPass     = "pass"
	stepFail     = "fail"
	stepSkip     = "skip"

type checkStep struct {
	Name   string `json:"name"`
	Status string `json:"status"`
	Detail string `json:"detail,omitempty"`
	Hint   string `json:"hint,omitempty"`
}

type checkReport struct {
	Backend string      `json:"backend"`
	Passed  bool        `json:"passed"`
	Session string      `json:"session,omitempty"`
	Steps   []checkStep `json:"steps"`
	unknown bool
}

func (r *checkReport) add(name, status, detail, hint string) {
	r.Steps = append(r.Steps, checkStep{Name: name, Status: status, Detail: detail, Hint: hint})

func cmdCheck(args []string, stdout, stderr io.Writer) int {
	fs := newFlagSet("check <backend>", stderr)
	var o launchOptions
	var env multiFlag
	var all, static, keep, asJSON bool
	fs.BoolVar(&all, "all", false, "check every resolvable backend")
	fs.BoolVar(&static, "static", false, "profile and binary checks only (no model call)")
	fs.BoolVar(&keep, "keep", false, "keep the check session for inspection")
	fs.BoolVar(&asJSON, "json", false, "print JSON")
	fs.StringVar(&o.Cwd, "cwd", "", "working directory (default: a fresh temporary directory)")
	fs.StringVar(&o.Permissions, "permissions", "", "permission level (default: config, else auto)")
	fs.StringVar(&o.Model, "model", "", "model passed to the backend")
	fs.StringVar(&o.EnvFile, "env-file", "", "KEY=VALUE file for the agent")
	fs.StringVar(&o.Launcher, "launcher", "", "auto|setsid|systemd")
	fs.DurationVar(&o.MaxRuntime, "max-runtime", 2*time.Minute, "limit for the check run")
	fs.DurationVar(&o.Grace, "grace", 5*time.Second, "time between SIGTERM and SIGKILL")
	fs.Var(&env, "env", "KEY=VALUE for the agent (repeatable)")
	pos, err := parseArgs(fs, args)
	if err != nil {
		return exitUsage
	}
	o.Env = env
	var backends []string
	switch {
	case all && len(pos) == 0:
		if backends, err = profile.Names(config.BackendsDir()); err != nil {
			return fail(stderr, err)
		}
	case !all && len(pos) == 1:
		backends = pos
	default:
		fmt.Fprintln(stderr, "usage: fastener check <backend> | --all [--static] [--keep] [flags]")
		return exitUsage
	}

	reports := []checkReport{}
	code := exitOK
	for _, b := range backends {
		bo := o
		bo.Backend = b
		r := runCheck(bo, static, keep)
		if !r.Passed {
			code = exitFail
			if r.unknown && !all {
				code = exitNotFound
			}
		}
		reports = append(reports, r)
		if !asJSON {
			printCheck(stdout, r)
		}
	}
	if asJSON {
		writeJSON(stdout, reports)
	}
	return code
}

func printCheck(w io.Writer, r checkReport) {
	fmt.Fprintf(w, "fastener check %s\n", r.Backend)
	for _, s := range r.Steps {
		fmt.Fprintf(w, "  %-4s  %-8s %s\n", strings.ToUpper(s.Status), s.Name, s.Detail)
		if s.Hint != "" {
			fmt.Fprintf(w, "        hint: %s\n", s.Hint)
		}
	}
	verdict := "PASS"
	if !r.Passed {
		verdict = "FAIL"
	}
	fmt.Fprintf(w, "%s %s\n\n", verdict, r.Backend)
}

// runCheck uses a named result so the deferred cleanup step lands in the
// returned report (a deferred call runs after `return r` copies a plain result).
func runCheck(o launchOptions, static, keep bool) (r checkReport) {
	r = checkReport{Backend: o.Backend}

	p, err := prepare(o, checkPrompt)
	if err != nil {
		step := "profile"
		var se *stepError
		if errors.As(err, &se) {
			step = se.step
		}
		r.unknown = errors.Is(err, profile.ErrUnknownBackend)
		for _, s := range []string{"profile", "binary"} {
			if s == step {
				break
			}
			r.add(s, stepPass, "", "")
		}
		r.add(step, stepFail, err.Error(), "")
		return r
	}
	r.add("profile", stepPass, fmt.Sprintf("%s, permissions=%s", p.prof.Source, p.perms), "")

	detail := p.argv0
	if va := p.prof.Check.VersionArgs; len(va) > 0 {
		ctx, cancel := context.WithTimeout(context.Background(), 15*time.Second)
		cmd := exec.CommandContext(ctx, p.argv0, va...)
		cmd.Env = p.mergedEnv(o.Env)
		out, err := cmd.CombinedOutput()
		cancel()
		if err != nil {
			r.add("binary", stepFail, fmt.Sprintf("%s %s: %v: %s", p.argv0, strings.Join(va, " "), err, lastLines(string(out), 5)), "")
			return r
		}
		detail += " (" + firstLine(string(out)) + ")"
	}
	r.add("binary", stepPass, detail, "")
	if static {
		r.Passed = true
		return r
	}

	if o.Cwd == "" {
		tmp, err := os.MkdirTemp("", "fastener-check-")
		if err != nil {
			r.add("launch", stepFail, err.Error(), "")
			return r
		}
		defer os.RemoveAll(tmp)
		o.Cwd = tmp
	}
	o.Prompt = checkPrompt
	o.Labels = map[string]string{"fastener.check": "true"}

	v, err := launch(o)
	if v != nil {
		r.Session = v.Session.Name
		defer r.cleanup(v, keep)
	}
	if err != nil {
		hint, more := "", ""
		if v != nil {
			hint, more = diagnose(p.prof, v)
		}
		r.add("launch", stepFail, joinDetail(err.Error(), more), hint)
		return r
	}
	if missing := missingFiles(v.Dir); len(missing) > 0 {
		r.add("launch", stepFail, "missing: "+strings.Join(missing, ", "), "")
		return r
	}
	r.add("launch", stepPass, "session "+v.Session.Name, "")

	v, err = waitEnded(v.Session.Name, o.MaxRuntime+o.Grace+30*time.Second)
	if err != nil {
		r.add("exit", stepFail, err.Error(), "")
		return r

	s := v.Status
	if s.EndedBy != session.EndedByExit || s.ExitCode == nil || *s.ExitCode != 0 {
		hint, more := diagnose(p.prof, v)
		r.add("exit", stepFail, joinDetail(describeEnd(v), more), hint)
		return r
	}
	r.add("exit", stepPass, "exit 0", "")

	if p.rendered.Parser == "none" {
		r.add("parse", stepSkip, "backend has no parser", "")
	} else {
		var problems []string
		if s.ConversationID == "" {
			problems = append(problems, "no conversation_id")
		}
		if s.FinalMessage == "" {
			problems = append(problems, "no final_message")
		}
		if s.AgentError != nil && *s.AgentError {
			problems = append(problems, "agent reported an error")
		}
		if s.ParseErrors > 0 {
			problems = append(problems, fmt.Sprintf("%d unparseable lines", s.ParseErrors))
		}
		if len(problems) > 0 {
			hint, _ := diagnose(p.prof, v)
			r.add("parse", stepFail, strings.Join(problems, "; "), hint)
			return r
		}
		r.add("parse", stepPass, "conversation "+s.ConversationID, "")

		return r
	}

// cleanup is deferred, so it always runs and is always the last step.
func (r *checkReport) cleanup(v *session.View, keep bool) {
	if cur, err := loadView(v.Session.Name); err == nil && (cur.Alive() || len(cur.Orphans) > 0) {
		if err := stopSession(cur, 0, "rm"); err != nil {
			r.add("cleanup", stepFail, err.Error(), "")
			r.Passed = false
			return
		}
	}
	if keep {
		r.add("cleanup", stepPass, "kept "+v.Session.Name, "")
		return
	}
	if err := os.RemoveAll(string(v.Dir)); err != nil {
		r.add("cleanup", stepFail, err.Error(), "")
		r.Passed = false
		return
	}
	r.add("cleanup", stepPass, "removed", "")
}

func waitEnded(name string, timeout time.Duration) (*session.View, error) {
	deadline := time.Now().Add(timeout)
	for {
		v, err := loadView(name)
		if err != nil {
			return nil, err
		}
		if !v.Alive() {
			return v, nil
		}
		if time.Now().After(deadline) {
			_ = stopSession(v, 0, "stop")
			return nil, fmt.Errorf("session did not end within %s", timeout)
		}
		time.Sleep(100 * time.Millisecond)
	}
}

func missingFiles(d session.Dir) []string {
	var missing []string
	for _, p := range []string{d.SessionPath(), d.PromptPath(), d.PlanPath(1), d.LauncherPath(1), d.StatusPath(), d.OutputLog()} {
		if _, err := os.Stat(p); err != nil {
			missing = append(missing, p)
		}
	}
	return missing
}

func describeEnd(v *session.View) string {
	s := v.Status
	switch {
	case v.State == session.StateLost:
		return "monitor lost"
	case s.EndedBy == session.EndedByLimit:
		return "killed at --max-runtime"
	case s.Signal != "":
		return fmt.Sprintf("ended_by=%s, killed by %s", s.EndedBy, s.Signal)
	case s.ExitCode != nil:
		return fmt.Sprintf("ended_by=%s, exit code %d", s.EndedBy, *s.ExitCode)
	}
	return "ended_by=" + s.EndedBy
}

// diagnose matches the profile's patterns against everything the agent said.
// It returns a hint, or, when nothing matches, the stderr tail as extra detail.
func diagnose(p *profile.Profile, v *session.View) (hint, detail string) {
	errText, _ := os.ReadFile(v.Dir.StderrLog())
	outText, _ := os.ReadFile(v.Dir.OutputLog())
	corpus := []string{string(errText), string(outText), v.Status.FinalMessage, v.Status.Error}
	for _, d := range p.Check.Diagnose {
		re := regexp.MustCompile(d.Match) // validated at load
		for _, c := range corpus {
			if c != "" && re.MatchString(c) {
				return d.Hint, ""
			}
		}
	}
	if v.Status.EndedBy == session.EndedByLimit {
		return timeoutHint, ""
	}
	if tail := lastLines(string(errText), 20); tail != "" {
		return "", "stderr:\n" + tail
	}
	return "", ""
}

func joinDetail(a, b string) string {
	if b == "" {
		return a
	}
	return a + "\n" + b
}

func firstLine(s string) string {
	s = strings.TrimSpace(s)
	if i := strings.IndexByte(s, '\n'); i >= 0 {
		return s[:i]
	}
	return s
}

func lastLines(s string, n int) string {
	lines := strings.Split(strings.TrimRight(s, "\n"), "\n")
	if len(lines) > n {
		lines = lines[len(lines)-n:]
	}
	return strings.TrimSpace(strings.Join(lines, "\n"))
}
```

````markdown
# Fastener `--json` output (schema_version 1)

The `--json` output of `run`, `inspect`, `ps`, `backends`, `check` and `version` is
a stable contract. Human-readable output is not. Within a schema version, fields are
only added, never removed or repurposed. Absent optional fields are omitted, not null.

## `inspect <name> --json` and `run --json`

| Field | Meaning |
|---|---|
| `schema_version` | 1 |
| `name`, `backend` | Session name and backend |
| `state` | Effective state: `starting`, `running`, `exited`, `lost` (inferred: not exited and the monitor is not alive), `restore-failed` |
| `orphans` | Number of live processes still carrying this session's marker (lost sessions only) |
| `session` | Contents of `session.json` (intent) |
| `status` | Contents of `status.json` (runtime facts; see below) |
| `plan` | The current generation's launch plan (`argv`, `profile_sha256`, …) |
| `launcher` | The launcher record (`launcher`, `monitor`, `boot_id`) |
| `paths` | `dir`, `output_log`, `stderr_log`, `monitor_log` |

`status` fields:
- `state`, `generation`
- `monitor`, `agent`: `{pid, start_time}`
- `pgid`, `boot_id`
- `started_at`, `ended_at`
- `ended_by`: `exit` | `limit` | `stop` | `signal` | `launch-failed`
- `exit_code`, `signal` (a name, e.g. `SIGKILL`), `error`
- parser fields: `conversation_id`, `final_message` (truncated to 64 KiB), `agent_error`, `usage` {`input_tokens`, `output_tokens`, `cost_usd`}, `parse_errors`
  - `usage.input_tokens` counts *all* input tokens for the run, including cache reads and writes. This differs from Anthropic's own `usage.input_tokens`, which excludes cache tokens.
- `updated_at`

## `ps --json`

An array of `{name, backend, state, created_at, ended_at?, ended_by?, exit_code?, orphans?, labels?}`, newest first.

## `check --json`

An array, one entry per backend checked: `{backend, passed, session?, steps: [{name, status, detail?, hint?}]}`.
- `name` is one of `profile`, `binary`, `launch`, `exit`, `parse`, `reply`, `cleanup`.
- `status` is `pass`, `fail` or `skip`.

## `backends --json`

An array of `{name, source, sha256, command, parser, permissions}`, or `{name, error}` for a profile that fails to load.

## Exit codes

- **`wait`:**
  - the agent's exit code;
  - 128+N if the agent was killed by signal N;
  - 124 if `--timeout` elapsed;
  - 125 for `launch-failed`, `lost` or `restore-failed`;
  - 127 for an unknown session.
- **Other commands:**
  - 0 for success;
  - 1 for failure;
  - 2 for usage errors;
  - 127 for an unknown session or backend.

As with Podman, `wait`'s 124, 125 and 127 can collide with real agent exit codes. `inspect --json` is authoritative.
````
